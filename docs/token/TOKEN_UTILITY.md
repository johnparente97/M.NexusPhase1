# Nexus Token Utility & Economic Model Specification

## Core Principle
- **USDC pays for services**. All capability costs, compute leases, storage fees, and provider pricing are dollar-denominated in USDC.
- **NEX coordinates participation**. The provisional token (NEX) serves strictly as an optional utility, bonding, reputation, and governance token.
- **NEX is never required to use core Nexus capabilities**.

---

## 1. Non-Transferable Service Credits Isolation
Service credits are managed separately from NEX token balances:
- **Nontransferable**: Cannot be withdrawn, traded, or converted to NEX.
- **Protocol-Only**: Apply exclusively to Nexus protocol fees, never provider base prices.
- **Capped**: Benefits are capped by actual fees paid and available benefit-pool funding.

---

## 2. Four Isolated Staking Purposes
1. **Access Staking**: Lock tokens for Nexus protocol fee discounts (10%–35%), increased concurrency, and priority queue placement.
2. **Provider Bonds**: Providers post accountable collateral scaled to transaction volume, risk tier, and SLA commitments.
3. **Curation Staking**: Curators stake behind provider lists and benchmark accuracy. Verified manipulation results in slashing under strict due process.
4. **Governance Signaling**: Participate in community parameter signaling and RFC discussions.
