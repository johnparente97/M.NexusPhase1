# Nexus Governance Roadmap

## Phased Rollout Schedule

### Phase 0 — Core Team & Multisig Administration
- Public changelogs, public RFCs, community discussions.
- Security council handles emergency operational actions.

### Phase 1 — Non-Binding Token Signaling
- Token-weighted signaling on community proposals.
- No direct smart-contract execution or automated treasury transfer.

### Phase 2 — Parameter Governance
- Timelocked execution for noncritical parameters, grants, and schema updates.
- Quorum requirements, proposal thresholds, and delegation mechanisms.

### Phase 3 — Mature Ecosystem Governance
- Expanded parameter control following security audits, legal review, and operational maturity.
- Emergency Security Council retains narrowly defined emergency pause powers with mandatory public postmortems.
