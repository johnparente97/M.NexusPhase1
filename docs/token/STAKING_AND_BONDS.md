## 2. Provider Security Bonds & Slashing Due Process
- **Bond Sizing**: Scaled to provider transaction volume, capability risk category, and SLA commitments.
- **Slashing Due Process**: Slashing occurs only for proven, verifiable misconduct (e.g. fraudulent execution proofs, receipt tampering, malicious data handling).
- **Appeal Window**: 14-day challenge and appeal window before any collateral is slashed.
